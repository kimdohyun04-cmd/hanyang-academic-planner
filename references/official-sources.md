# 공식 자료

기준일: 2026-09-17

## 우선 확인 순서

1. 학생 본인의 포털 졸업사정조회
2. ERICA 학사안내의 최신 졸업요건 기준표
3. 해당 학기 학사공지
4. 학과·단과대학 세부 내규
5. 학사운영팀 또는 단과대학 담당자 확인

## 갱신 규칙

- 학기 시작 전과 졸업사정 기간 전에 최신 공지로 다시 확인한다.
- 입학연도, 편입 여부, 다전공 여부, 학과에 따라 다른 기준을 섞지 않는다.
- 포털 값과 공개 자료가 다르면 포털 화면을 보존하고 담당 부서에 확인한다.
- 과거 공지의 날짜와 예시를 현재 일정으로 사용하지 않는다.
