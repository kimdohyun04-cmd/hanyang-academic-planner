# 개인정보 및 오답 방지

## 개인정보

- 아이디, 비밀번호, OTP, 세션 URL을 입력으로 받지 않는다.
- 이름과 학번은 개인용 입력 파일에만 저장한다.
- 배포용 스킬 폴더에 실제 학생 데이터를 포함하지 않는다.
- 공개 보고서는 이름을 비식별 처리하고 학번을 마스킹한다.
- 화면 캡처는 주소창을 제거하고 이름·학번·성적·수강정보를 불투명하게 가린다.

## 정확성

- 계산 결과와 AI 설명을 분리한다.
- 수강 중 학점은 취득 학점으로 확정하지 않는다.
- 빈칸, 예외, 학과 내규는 임의로 확정하지 않는다.
- 모든 결과에 데이터 기준일과 공식 출처를 표시한다.
- 졸업, 휴학, 다전공 포기 같은 중요한 판단은 담당 부서 확인을 권고한다.

## 자동화 범위

- 허용: 조회 자료 구조화, 규칙 계산, 설명, 계획, 문의문 작성
- 금지: 로그인 정보 수집, 자동 신청, 자동 포기, 무확인 제출
